# THADEN DOKUMENTATION V21

Schrittweiser Arbeitsablauf mit Zwischen-Speicherung und automatischem Weiterblättern.

1. Auftrag
2. Gerechtfertigt?
3. Fotos
4. Nach Instandsetzung
5. Datum / Uhrzeit
6. Einblasprotokoll
7. Abschluss / PDF

Jeder Schritt kann gespeichert werden. Danach springt die App automatisch zum nächsten Abschnitt. Das Gesamt-PDF wird erst nach Abschluss der sechs Arbeitsschritte freigegeben.
