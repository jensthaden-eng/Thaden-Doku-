## V8 – App-Icon
Das App-Icon verwendet jetzt eine vollständig ausgefüllte anthrazitfarbene Bildfläche (#081018) ohne transparente Ecken oder weißen Außenrand. Das TD-Logo bleibt unverändert.


### V9 – App-Icon
Das App-Icon wurde auf eine vollflächige anthrazitfarbene quadratische Bildfläche umgestellt. Es enthält ausschließlich das TD-Zeichen (weiß/orange), ohne orange Außenrahmen und ohne zusätzlichen Text. Die iPhone-typische abgerundete Form wird vom Homescreen übernommen.


### V10 – freigegebenes TD-App-Icon
Das zuletzt bestätigte TD-Logo wurde als vollflächiges App-Icon übernommen. Keine zusätzliche weiße Umrandung, kein orangefarbener Außenrahmen und kein Text unter dem Logo.


### V11 – Mobile-Layout
Die acht Funktionskreise wurden auf kleinen Bildschirmen kompakter angeordnet, damit alle Kreise vollständig innerhalb der Home-Seite sichtbar bleiben und die untere Navigation nicht überlagert wird.
