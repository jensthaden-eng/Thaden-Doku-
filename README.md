# THADEN DOKUMENTATION – V31 Tablet

V31 passt die geschützte PIN-Startseite für Tablets/iPad an, insbesondere im Querformat:
- deutlich größere Kopf-/Logo-Darstellung
- Schloss zentral und gut sichtbar
- PIN-Tastatur passend zur Tablet-Größe
- kein Scrollen auf der PIN-Startseite
- vorhandene Funktionen und der bestehende Arbeitsablauf bleiben erhalten

Standard-PIN beim ersten Start: 1234
